OpenBot agent

Bot builder

by OpenBot user · 10 skills

Designs, audits and improves OpenBot agents: profile, AGENTS.md, skills, memories, routines and delegation. It returns a diagnosis, rewritten instructions and validation tests — and changes another bot only with your approval.

Download the zip View source

Zip, ~28 KB · Manifest at the root · nothing is uploaded when you install

Install

  1. Download the zip to the computer that runs OpenBot.
  2. In OpenBot open Server settings → Import.
  3. Choose Select file…, pick the zip, then import the agent Bot builder.
  4. Set provider and model, then give it a real audit as the first task.

A second import of the same file does not overwrite the first copy; it creates another. Routines are not included in this package.
